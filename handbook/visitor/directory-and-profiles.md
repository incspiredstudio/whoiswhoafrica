# Directory and profiles

The directory is a browsable record of people, entrepreneurs, businesses and institutions. Each profile states facts, shows a source beside every fact, and gives anyone a way to correct, claim, report or ask to remove it without an account.

## Browse the directory

1. Open the directory and choose a list: All, People, Entrepreneurs, Businesses or Institutions.
2. Type a name, organisation or keyword in the box at the top of the list to narrow that list only.
3. Choose filters. They apply at once and there is no Apply button.
4. Sort by Name A to Z or Recently updated, and switch between grid and list view.
5. Open a profile. Sixteen profiles show per page.

| Filter | Applies to |
|---|---|
| Industry, Country, City | All lists |
| Profession | People and Entrepreneurs |
| Organisation type | Businesses and Institutions |

The filters are kept in the page address, so a filtered view can be shared as a link. The industries page lists every sector with a count, and each industry page shows that sector's profiles and stories.

Lists show reviewed profiles only. A profile that is still waiting for review is never named on a list.

## What a profile page contains

| Part | Content |
|---|---|
| Header | Portrait or logo, name, title and organisation, city, country, industry and type. There is no cover image. |
| Award panel | If the profile has a live nomination or win, a panel names the category and links to it. |
| About | The biography. |
| Type sections | Ventures for entrepreneurs, mandate and history for institutions, career, education, milestones, leadership, products and services, achievements and media. Only sections with content appear. |
| Key facts and sources | A table of facts, each with its source and the date it was retrieved. A fact without a source is not shown. |
| Related stories | Stories that link to the profile. |
| Side column | Contact, the "Something wrong?" actions and a share preview. |

An individual's profile holds professional facts only: name, current title and organisation, industry, public-record roles, published awards and an official website. A profile never shows an email address or phone number. A visitor who wants to reach the owner uses the enquiry form on the profile, and staff relay the message. If the owner has asked for enquiries to be switched off, the page says so.

## What a visitor may find on a profile address

| Situation | What the visitor gets |
|---|---|
| Published and reviewed | The full page, listed in lists, search and the sitemap |
| Published, review pending (organisations only) | The page, with the label "Compiled automatically from public sources. Human review pending." and a link to correct or remove it. It is not listed, not in the sitemap and tells search engines not to index it. It can still be found by search or a direct link. |
| Unpublished, removed or suppressed | A "gone" page (410). Search engines drop it. |
| Not public (draft or rejected) | A not found page (404) |
| Address changed | A redirect from the old address |

## Actions on a profile

All four work without an account or payment.

| Action | What happens next |
|---|---|
| [Claim this profile](/visitor/claim-a-profile) | A claim reaches staff and is decided within 5 days |
| [Suggest a correction](/visitor/corrections-and-removals) | Staff apply it or decline it with a reason |
| [Request removal](/visitor/corrections-and-removals) | A valid request hides the profile within 2 business days |
| [Report this profile](/visitor/corrections-and-removals) | Staff can hide the profile at once while they look into it |

Staff side: [Profile review and publication states](/staff/profile-review).
