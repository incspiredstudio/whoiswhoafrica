# Events

Events list conferences, launches, ceremonies and other gatherings linked to the people and ideas on the record. Events are their own content type, separate from stories. The site lists them and links to the organiser's registration page. It never takes a registration or a payment.

## Where a visitor finds events

| Place | What shows |
|---|---|
| Header and footer | An Events link |
| Home | The next three upcoming events as compact rows and an "All events" link. The section is absent when no event is upcoming. |
| End of a story | A Related event card, when the story links an event |

## Use the Events list

1. Open Events. The header band shows the page title and a Next up block with the soonest upcoming event.
2. Filter by City or Industry. The filter applies at once, and Clear appears while a filter is on.
3. Read Upcoming events, soonest first, grouped by month. Each row shows the date, title, place, organiser and status (Upcoming or Online).
4. Below that, Past events appear in a muted style, newest first.
5. Open an event.

If nothing matches, the page says "No upcoming events match" and offers to clear the filters.

## The event page

| Block | Content |
|---|---|
| Poster | The date in large type, status, title, place and organiser. The colour block is orange for an upcoming event and charcoal for a past one. |
| Details card | When, Where, Organiser, Cost and a Register button |
| Text | The summary, then the body |
| Related stories | Stories that link to the event, when there are any |
| More events | The next upcoming events |

The Register button opens the organiser's own site in a new tab. A past event shows "This event has ended" and no button. Cost is text only, for example "Free".

## Rules

1. Upcoming or past follows the date. An event is upcoming until its end date, or until its start date if it has no end.
2. Only published events appear. A draft, scheduled or removed event is absent everywhere and its page is not found.
3. Events are never Sponsored.
4. Events are not in site search.
5. Each published event page carries structured data that matches the visible details.
