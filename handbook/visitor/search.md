# Search

Search lets a visitor find a person, organisation or story by typing a name or keyword. One search returns profiles and stories together and never returns anything that is not public.

## Use search

1. Click the search icon in the header, or open the search page.
2. Type a name, organisation, title, industry or keyword.
3. Read the results. They are grouped under Profiles and Stories, with one count for both.
4. Open a result.

## What the results contain

| Group | Matched on | Order |
|---|---|---|
| Profiles | Name, organisation, title, industry and biography | Profiles whose name matches come first |
| Stories | Title and body | Publishing order |

Events are not part of site search. Visitors find them through the Events link in the header and footer, the Home page and stories that link to an event.

## Search and the directory lists

Each directory list also has its own search box. That box only narrows the list you are on, and it works together with the filters. The site search crosses profiles and stories.

## Rules

1. **Nothing non-public appears.** Removed, suppressed, rejected, draft and hidden profiles are never returned. Draft, scheduled and removed stories are never returned.
2. **A removal takes effect in search at once.** When staff unpublish, remove or suppress a profile, its search entry is deleted in the same step.
3. **Pending profiles can appear.** An organisation profile awaiting review is left off lists but can be found by search, always with its review label.
4. **Payment never changes the order.** Results follow relevance and name match only.

## What the visitor sees in each state

| State | Message |
|---|---|
| Empty search box | An invitation to type a name, organisation or keyword, with a note that only public profiles and stories are searched |
| Results | A count, then Profiles, then Stories |
| No results | "No results", with a suggestion to check the spelling or try fewer words, and a button to browse the directory |
