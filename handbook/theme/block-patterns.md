# Block patterns and page copy

Page copy is edited in the native WordPress block editor. The theme supplies block patterns, so staff edit words and the theme owns structure. There is no page builder. This page lists what editors change, the patterns available and what is locked.

## What staff edit and what is fixed

| Edited in the editor | Fixed in the theme |
|---|---|
| Words on About, FAQ, Awards rules, Complaints, legal pages and the Nominate guidance | Header, footer, cookie notice and the structure of menus |
| The order and number of FAQ groups and questions | Every form, its fields, bot check and privacy notice |
| Home text lines and calls to action | The profile and story templates and their states |
| Page titles, descriptions and share images | Colours, fonts, spacing and motion |
| Images from the media library | Whether a page is public, and every label |

Staff never type a status, a label or a number the system knows. Counts, the edition name and the awards stage come from data.

## Edit a page

1. Open Pages and choose the page.
2. Edit text in place. To add a section, insert a pattern from the pattern list.
3. Check the preview.
4. Publish or update.

Editors and Administrators edit pages by default. A Reviewer does not unless the Administrator grants it.

## The FAQ block

The FAQ is a repeatable question-and-answer block with groups. Each group has a heading and one or more questions. Each question has a title and a rich answer that can include links.

1. Add a group, then add questions to it.
2. Drag groups and questions into order.
3. Link to other pages by choosing them from a list, so a renamed page does not break the link.
4. The first question opens by default and the rest are collapsed.

Answers that state a time limit (acknowledge in one business day, resolve corrections in seven days, hide a valid removal in two, decide a claim in five) must match the real process. Whoever changes a time limit changes the FAQ in the same step.

## Dynamic blocks

These pull from the system and cannot be typed over.

| Block | Shows | Options |
|---|---|---|
| Figures | Counts of public profiles, industries, countries and stories | None |
| Awards stage button | One button whose label and link follow the awards stage | None |
| Awards categories | Groups and categories from Award categories | None |
| Edition label | The edition name from settings | None |
| Profile rail ("On the record") | Profiles chosen by the Home curation mode | Which curation setting to follow |
| Story track | Stories chosen by the Stories curation mode | Which curation setting, and count |
| Nominees grid | Live nominees, only once published | Group filter on or off |
| Newsletter sign-up | The sign-up form | Heading and sentence |

## Event pieces

The theme supplies an agenda row, an event poster header, a details card, a Next up block, a Related event card for the end of a story, a Related stories list for the event page and the Home Events block. Staff do not edit their structure.

## Locked parts

These are built in code and are not blocks:

- The hero videos, the three colour scenes, scroll effects and every animation.
- Forms: claim, correct, remove, report, contact, Get listed, data rights, nomination steps, comments and unsubscribe.
- The pending-review label, the Sponsored notice and the staff preview banner.
- The sitemap, robots file, canonical address, robots meta and structured data.

## Who supplies the words

Brand supplies the mission, vision and values. Legal supplies the legal wording. Update the page when the approved text arrives and remove any placeholder note block.
