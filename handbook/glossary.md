# Glossary

This page defines the product terms used in the handbook, with a link to the page that explains each in more detail.

## Product terms

| Term | Meaning |
|---|---|
| Profile | A public record of a person, business or institution, with a source beside each fact |
| Review pending | The state of a published organisation profile that no person has reviewed. It shows the label "Compiled automatically from public sources. Human review pending." Lists show reviewed profiles only. See [Profile review](/staff/profile-review). |
| Review queue | Where staff check imported records before publishing |
| Import batch | One delivery of records, which can be filtered on the Profiles screen |
| Claim | A request from a person or representative to take care of a profile. Decided within five days. See [Claims](/staff/claims). |
| Claimed | A profile whose claim a staff member approved. Staff see a checkmark. The public sees nothing, and the Claim button disappears. |
| Assigned user | The staff user kept on a claimed profile to update it. Their edits are held for approval. |
| Featured | A flag on stories only, using the WordPress sticky flag. Profiles are never Featured. |
| Sponsored | The label on a story whose placement was paid for. Always shows the sponsor's name. Only stories carry it. See [Trust and independence](/concepts/trust-and-independence). |
| Sponsored story deal | One sponsor, one story and one paid slot, tracked on the Sponsored stories screen in four steps |
| Slot | The labelled placement of a sponsored story on Home, Stories or both, for set dates |
| Event | A content type for something happening on a date, with its own list and pages. Never Sponsored. See [Events](/visitor/events). |
| Story | An article: interview, feature, spotlight, opinion, announcement or news |
| Nomination | A person or organisation put forward for an award. Its stage is Nominated or Winner and its status is Live or Not live. |
| Nominator | Someone who submits a nomination. Their name is never shown to the nominee or the public. |
| Nominations switch | The single switch that opens or closes nominations, a toggle on the Nominations screen |
| Offline judging | Judges decide and score outside the site. Staff only record the outcome. |
| Suppression list | People and organisations who asked to be removed, so they are never republished |
| Bulk unpublish | Unpublishing every profile that matches a filter at once, with a reason. Reversible and audited. |
| Gone (410) | The response a removed page returns, so search engines drop it |
| Not found (404) | The response for a page that is not public |
| Noindex | An instruction that tells search engines not to list a page |
| Curation | Choosing what Home and Stories show: Latest, Random, Manual or Pinned then fill |
| Single-use link | A signed link emailed to someone that works once and expires. See [The no-accounts model](/concepts/no-accounts). |
| Capability | A named permission. Roles are default bundles of capabilities. |
| Role | Reviewer, Editor or Administrator, plus any role the Administrator creates. See [Roles](/concepts/roles). |
| Fixed capability | A permission that stays with the Administrator and cannot be granted to others |
| Enquiry | A message from the Get listed, Contact or profile enquiry form |
| Customer | A sponsor record: name, segment and contact |
| Sprint tracking | A theme setting that shows or hides the sprint card and the Sprint thresholds screen. See [Theme settings](/theme/theme-settings). |
| Audit log | An append-only record of staff actions with a hash chain |
| Purge log | A list of unpublish actions and their cache purges |

## Technical terms

| Term | Meaning |
|---|---|
| Parent theme `whoiswho` | The reusable theme holding templates, patterns and components |
| Child theme `whoiswho-child` | The active theme holding brand values and site-specific overrides |
| Tokens | Named brand values for colour, type, spacing and motion. See [Brand tokens](/theme/brand-tokens). |
| Block pattern | A ready-made arrangement of blocks that an editor inserts and edits |
| `whoiswho-core` | The plugin that holds the product logic |
| `whoiswho-guard` | The always-on plugin that enforces the rules |
| wpDiscuz | The comments plugin used on stories |
| Action Scheduler | The library that runs queued background jobs |
| Read model | A fixed way for public pages to read profiles and stories so hidden items cannot appear |
| Migration | A forward-only change to the database structure that adds before it removes |
| Runbook | The written procedures for deploy, rollback, restore and incidents |
