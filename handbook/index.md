# WHOISWHO Handbook

This handbook explains how WHOISWHO works: what visitors can do, how staff run each part of the site, the ideas the product is built on, how the theme is edited, and how the site is kept healthy. It is written for staff, editors, partners and new team members.

## What WHOISWHO is

WHOISWHO is an African discovery, recognition and media platform. It records the people, businesses and institutions shaping the continent, tells the stories behind them, and recognises achievement through independent awards. Three words organise everything: Influence, Achievement and Legacy.

## What the site offers

| Area | What it does |
|---|---|
| Directory | Browse people, entrepreneurs, businesses and institutions, with filters. Every fact on a profile has a source beside it. |
| Search | One search across profiles and stories. |
| Stories | Interviews, features, spotlights, opinion, announcements and news. |
| Events | A calendar of conferences, launches and ceremonies, with a link to the organiser's registration page. |
| Awards | Rules, nominations, nominees and winners. |
| Get listed and contact | Forms that reach the team. Nothing is bought or paid for on the site. |
| Trust pages | About, FAQ, complaints and takedown, data rights and legal pages. |

## Rules that do not change

1. **Public only after review.** An individual's profile is public only after a person approves it. An organisation can be live earlier, but it carries the label "Compiled automatically from public sources. Human review pending."
2. **Money never buys recognition.** Payment never affects nominations, winners, ranking, Featured, Claimed or any label. The only thing money buys is a story placed in a labelled "Sponsored by" slot for set dates.
3. **There are no public accounts.** Visitors use forms and single-use email links. Only staff sign in.
4. **Privacy by default.** The site stores as little personal data as possible, answers requests within published time limits, and hides a profile within two business days of a valid removal request.
5. **Claimed is a staff mark.** Staff see a checkmark on a claimed profile. The public sees nothing, and the Claim button disappears.

## How the site is put together

| Part | What it is |
|---|---|
| WordPress | The content system: posts, users, roles, sign-in, taxonomy terms and the media library. |
| Plugin `whoiswho-core` | The product logic: directory, review, claims, sponsored stories, awards, enquiries, requests and the audit log. |
| Plugin `whoiswho-guard` | Always-on rules that hold whatever else is installed. |
| Parent theme `whoiswho` and child theme `whoiswho-child` | The public pages. The child is the active theme and holds the brand values. |
| Third-party plugins | Two-factor sign-in, comments, spam protection, a role editor and a cache plugin. |
